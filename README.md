# daengs-legal

댕스(Daengs) 앱의 **공개 문서**를 담는 저장소입니다. 앱 코드는 여기 없습니다.

| 문서 | 주소 | 어디에 쓰나 |
| --- | --- | --- |
| 개인정보처리방침 | `/privacy.html` | Play Console → 앱 콘텐츠 → 개인정보처리방침 |
| 계정·데이터 삭제 | `/delete.html` | Play Console → 앱 콘텐츠 → 데이터 삭제 |

## 왜 저장소를 따로 두나

플레이스토어는 개인정보처리방침과 계정 삭제 안내를 **웹에서 열리는 주소**로
요구합니다. 앱 저장소(`SAJOYO/DAENGS_APP`)는 비공개라 GitHub Pages 를 쓸 수 없고,
공개로 바꾸면 코드가 전부 공개됩니다. 그래서 **문서만 담는 공개 저장소**를 따로 둡니다.

## 고칠 때 주의

⚠️ **앱이 실제로 하는 일과 어긋나면 안 됩니다.** 구글은 Play Console 의
데이터 안전 양식과 이 문서를 **대조**합니다. 한쪽만 고치면 심사에서 반려됩니다.

수집 항목이나 제3자 전달처가 바뀌면 **이 문서와 데이터 안전 양식을 같이** 고치세요.
